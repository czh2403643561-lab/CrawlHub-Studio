# CrawlHub Studio

## 项目是什么

CrawlHub Studio 是一个个人使用的 TikTok 商品选品数据工作台，用于整理、查看和筛选通过采集工具获得的 TikTok 商品榜数据，帮助快速发现值得进一步研究的商品。

## 核心需求

- 导入已有采集数据文件，并保存商品基础信息
- 展示商品图片、名称、价格、GMV、点击量、CTR、评分、店铺、排名等数据
- 搜索商品，根据关键字段筛选，并按指标排序
- 查看商品详情、收藏商品、添加简单状态或标签

## 使用方式

用户在电脑上启动本地 Web 服务，通过浏览器访问工作台，导入 TikTok 商品采集数据后进行浏览、筛选和管理。

## 当前阶段目标

完成一个可运行的本地商品数据工作台：能导入商品数据、清晰展示商品列表、快速筛选目标商品，并保存个人选品标记。

## 关键约束

- 当前仅个人使用，不考虑多人账号和在线服务
- 优先简单快速实现，不提前设计复杂系统
- 数据来源保持灵活，方便未来接入浏览器插件自动同步
- 第一阶段不开发 AI 分析、供应链分析和第三方接口
